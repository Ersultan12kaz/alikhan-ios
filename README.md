# Алихан: iPhone қосымшасы

iPhone-дағы «құлақ, ауыз және пульт». Ойлау жұмысының бәрі серверде (`http://100.78.149.53:8000`, тек Tailscale арқылы).
Mac жоқ, сондықтан құрастыруды Codemagic жасайды: `xcodegen generate` → қолтаңба → IPA → TestFlight.

## Ерсұлтан жасайтыны

App Store Connect API кілті мен сертификат ClipPay-де бар, соларды қайта қолданамыз (жаңа сертификат жасалмайды).
Bundle ID-лерді Codemagic өзі тіркейді.

1. **App Store Connect → Мои приложения → +:** «Алихан», Bundle ID `kz.ersultan.alikhan` (тізімде болмаса, алғашқы құрастырудан кейін шығады), SKU `alikhan`.
2. **GitHub:** бос жабық `Ersultan12kaz/alikhan-ios` репозиторийін ашу (README-сіз). Сосын жіберу:
   ```
   cd ~/alikhan-ios
   git remote add origin https://github.com/Ersultan12kaz/alikhan-ios.git
   git push -u origin main
   ```
3. **Codemagic → Add application →** `alikhan-ios`.
4. **Codemagic → alikhan-ios → Environment variables:** `appstore_credentials` тобын ClipPay-дегідей толтыру (4 айнымалы, бәрі Secure). Мәндері ClipPay-дегімен бірдей: `.p8` және `~/clippay-keys/ios_distribution_private_key`.
5. **Start new build →** `alikhan-ios`. Қате шықса, журналдың соңғы жолдарын маған жіберіңіз.
6. **iPhone:** TestFlight арқылы «Алиханды» орнату. Tailscale қосулы болсын.

## «Алихан басқару» Shortcut-ы (музыка басқару)

iOS басқа қосымшаның ойнатуын басқаруға рұқсат бермейді. Сондықтан қосымша мына Shortcut-ты іске қосады: `next:`, `previous:`, `pause:`, `play:`, `volume:40`.

1. **Команды → +**, атауы дәл: **Алихан басқару**.
2. **Разделить текст**: мәтін — *Входные данные быстрой команды*, разделитель — *Пользовательский*, `:`.
3. **Получить объект из списка** → *Первый объект* (бұл — команда).
4. Тағы **Получить объект из списка** → *Объект по индексу* `2` (бұл — сан, тек дыбыс үшін).
5. **Если** (3-қадамдағы объект) *является* `next` → **Следующий трек**.
6. **Иначе если** / тағы **Если**: `previous` → **Предыдущий трек**; `pause` → **Воспроизвести/пауза** (Пауза); `play` → **Воспроизвести/пауза** (Воспроизвести); `volume` → **Задать громкость**, мәні 4-қадамдағы сан.
7. Shortcut баптауында «Показывать при запуске» өшірулі болсын.

Shortcut біткен соң `alikhan://` арқылы қосымшаға оралады.
Қосымша телефонда тексерілгенде, бұрынғы Shortcut-тағы **«Добавить новое напоминание»** бөлігін алып тастаңыз, әйтпесе еске салу екі рет қосылады.

## Серверге қосу керек (әлі жоқ)

Серверге мен тимедім. Мыналар қосымшада дайын, бірақ серверде жоқ:

1. **`action: "capture"`**: `arg` = `video` не `photo`, `url` = жүктеу мекенжайы (сол сервердің өзінде). Қосымша камераны ашып, `multipart/form-data` (`file` өрісі) арқылы жүктейді. Токен басқа серверге кетпесін деп, тек сол хостқа жүктейді.
2. **`GET /reminders/pending`**: жаңа еске салулар тізімі (`title`, `at`, `repeat`), бір-ақ рет берілсін. Қосымша оны минутына бір рет сұрайды, 404 болса 10 минутта бір.
3. **APNs push**: қосымша жабық не ұйықтап тұрғанда тапсырма біткенін және агент сұрағын жеткізу үшін. Серверге APNs кілті (`.p8`, Apple Developer → Keys) мен жіберу бөлігі керек. Қосымшаға push тіркеуін сосын қосамыз.

## Шектеулер (iOS)

- **Live Activity** тек қосымша ашық тұрғанда басталады. Siri арқылы «Алиханды аш» деп ашсаңыз, ол бірден басталады. iOS оны шамамен 8 сағаттан кейін жабады: қосымшаны қайта ашсаңыз, қайта басталады.
- **Dynamic Island-ты** кеңейтуді қосымша өзі шақыра алмайды. «Алихан» расталғанда ескерту (alert) жіберіледі, сонда Dynamic Island қысқа уақытқа кеңейеді.
- **Siri қосымшаны жаба алмайды.** «Алиханды тоқтат» тек микрофонды мен Live Activity-ді жабады.
- **Қоңырау** қосымша ашық тұрғанда ғана шалынады. Фонда iOS `tel://` ашуға рұқсат бермеуі мүмкін.
- **Батарея:** тыныштықта серверге ештеңе кетпейді. VAD сөз деп таныған бөлік қана AAC-ке сығылып `/wake/confirm`-ға кетеді. Есептегіш баптау бетінде.
