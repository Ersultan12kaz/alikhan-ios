# Тапсырма: «Алихан» серверіне iPhone қосымшасы үшін қосымшалар

Сен Ерсұлтанның «Алихан» дауыстық ассистентінің серверінде (Contabo, Ubuntu, `http://100.78.149.53:8000`, тек Tailscale) жұмыс істейтін Claude-сың. Жауаптарыңды қазақша, қысқа әрі нақты жаз.

iPhone қосымшасы дайын (`github.com/Ersultan12kaz/alikhan-ios`). Ол серверге «құлақ, ауыз және пульт» ғана, бүкіл ойлау серверде. Төмендегілер серверде әлі жоқ, соларды қос.

## Жалпы ережелер

- Қазір жұмыс істеп тұрған нәрсені бұзба: `/phone`, `/wake/confirm`, `/speak`, `/notifications`, ноутбук клиенті, WhatsApp. Жаңа өрістер тек **қосымша** болсын, ескі клиенттер оларды елемей жұмыс істей берсін.
- Барлық жаңа нүкте `Authorization: Bearer <токен>` тексерсін, жоқ болса 401.
- Пароль, логин, SMS код, cookie ешқашан журналға, дерекқорға, жауапқа жазылмасын.
- Әр бөлімнен кейін не жасалғанын, не тексерілгенін (`curl` нәтижесімен), не тексерілмегенін қысқа айт.
- Ақылы қызмет қоспа.

## 1. Қолданушыдан күтетін тапсырмалар (ask)

Қазір агент `deploy/ask` арқылы күтеді, сұрақ `/notifications`-та жай `voice_text` болып келеді, қолданушы «жасадым» деп жауап береді. Қосымшада енді «Тапсырмаларым» беті және әр тапсырмада «Орындадым» батырмасы бар. Сервер қай тапсырма орындалғанын нақты білуі керек.

1. `/notifications` элементіне өрістер қос (бұрынғы `id`, `voice_text` қалады):
   ```json
   {"id": "n123", "voice_text": "Сэр, TikTok-қа кіру керек...",
    "kind": "ask", "ask_id": "a42", "title": "TikTok-қа кіру",
    "url": "https://www.tiktok.com/login",
    "remote_browser_url": "http://100.78.149.53:6080/vnc.html?...",
    "created_at": "2026-11-08T21:40:00+05:00"}
   ```
   `kind`: `ask` (қолданушы бір нәрсе жасауы керек), `done` (тапсырма бітті), `message` (WhatsApp, қоңырау т.б.).
2. `POST /ask/{ask_id}/done` — қолданушы «Орындадым» басты. Агент сол тапсырманы жалғастырады. Жауап: `{"ok": true, "text": "айтылатын жауап", "audio": "<mp3 base64>"}`.
3. `POST /ask/{ask_id}/cancel` — қолданушы бас тартты, агент тапсырманы тоқтатады не басқа жол іздейді.
4. `GET /asks?status=pending` — әлі орындалмаған тапсырмалар тізімі (қосымша ашылғанда синхрондау үшін).
5. Бұрынғы «жасадым» (`/phone`, `text=жасадым`) жұмыс істей берсін: ол соңғы күтіп тұрған ask-ты жабады.

## 2. Сервердегі браузерге кіру (логин, пароль, SMS)

Агент TikTok, Kaspi, ClipPay сияқты сайттарда серверде жұмыс істейді. Қолданушы телефонда кірсе, сессия серверге өтпейді. Сондықтан қолданушы **сервердің өз браузерінде** кіруі керек.

1. Агенттің браузері тұрақты профильмен жұмыс істесін (Chromium/Playwright `user_data_dir`), сонда бір кірген соң cookie сақталады, қайта сұралмайды.
2. Сол браузерді көрсететін noVNC (не ұқсас тегін құрал) қос:
   - тек Tailscale интерфейсінде тыңдайды (`100.78.149.53`), сыртқа ашық емес;
   - әр ask үшін бір реттік, мерзімі шектеулі (мысалы 15 минут) сілтеме не құпия сөз;
   - телефон экранына ыңғайлы (масштаб, пернетақта).
3. Агент кіру керек болғанда: браузерде кіру бетін ашады → ask жасайды (`remote_browser_url` сол сілтеме) → қолданушы iPhone-да «Ашу» басып, сервер браузерінде өзі кіреді → «Орындадым» → агент жалғастырады.
4. Агент парольді ешқашан өзі енгізбейді, сақтамайды, оқымайды. Ол тек «кірдім бе» дегенді беттің күйінен тексереді.

## 3. Еске салулар

`GET /reminders/pending` — жаңа еске салулар тізімі: `[{"title": "...", "at": "2026-11-09T09:00+05:00", "repeat": ""|"daily"|"weekly"}]`. Әр еске салу бір-ақ рет берілсін (берілген соң белгіле). Қосымша минутына бір рет сұрайды. `/phone` жауабындағы `reminders` өрісі сол қалпында қалсын.

## 4. Видео не фото түсіру

1. «ClipPay-ге видео түсір» сияқты тапсырмада `/phone` жауабы:
   `{"action": "capture", "arg": "video"|"photo", "url": "http://100.78.149.53:8000/upload/{capture_id}"}`.
2. `POST /upload/{capture_id}` — `multipart/form-data`, өріс `file` (видео `video/quicktime`, фото `image/jpeg`), Bearer токенмен. Файлды тапсырмаға байланыстырып сақта, агентке беріп, жалғастыр.
3. `url` міндетті түрде осы сервердің мекенжайы болсын: қосымша токенді басқа хостқа жібермейді.

## 5. iPhone-ға push хабарландыру (APNs)

Қосымша фонда не жабық тұрғанда «тапсырма бітті» мен «сізді күтіп тұр» хабарлары жетуі үшін.

1. `POST /device` — `{"apns_token": "...", "platform": "ios", "bundle_id": "kz.ersultan.alikhan"}`. Токенді сақта (бірнеше құрылғы болуы мүмкін).
2. APNs-ке тікелей HTTP/2 + JWT (`.p8` кілт) арқылы жібер, бөгде ақылы қызметсіз. Керек: Key ID, Team ID `23L3826677`, `.p8` файлы. Кілтті Ерсұлтан Apple Developer → Keys бөлімінде жасап, серверге өзі салады. Ол репозиторийге не журналға түспесін.
3. `kind=ask` және `kind=done` болғанда push жібер: `alert` (қысқа мәтін), `sound: default`, `thread-id: alikhan`, ішінде `ask_id`.
4. Мұны жасап болған соң маған (iOS жағына) айт: қосымшаға Push Notifications құқығы мен токен тіркеуді қосамыз.

## 6. Тексеру

Әр нүктені `curl`-мен тексер (токенсіз 401, токенмен 200). ask ағынын басынан аяғына дейін бір рет жүргіз: агент ask жасайды → `/notifications`-та `kind=ask` шығады → `POST /ask/{id}/done` → агент жалғастырады. Нәтижесін қысқа есеп етіп бер.
